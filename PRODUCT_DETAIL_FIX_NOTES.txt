Database note:
The uploaded website ZIP did not contain data/catalog.db. The application expects the shared SQLite DB at ../SuperAdminRBPL/data/catalog.db by default, or the path set by SQLITE_DB_PATH. Product records themselves could not be inspected without that database. Keep the database available at the configured path before running the site.
